### Story 220 — BacktestOutcomeSimulator

**Arquivo:** `src/services/backtest_outcome_simulator.py`

**Modelo probabilístico:**
```
p_win = clip(0.45 × min(rr/2.0, 1.5) × (0.70 + conf×0.60), 0.10, 0.90)
```

**Comportamento:**
- `is_real=True` → preserva outcome e pnl_usd sem modificação
- `action="HOLD"` → `outcome=EXPIRED, pnl_usd=0.0`
- `outcome=UNKNOWN` + LONG/SHORT → simula via p_win com `random.Random(seed)`
- PnL: `allocated × (dist/entry) × leverage` (WIN: tp_dist; LOSS: sl_dist)

**Testes:** `tests/test_story_220_backtest_outcome_simulator.py` (9 testes)

### Story 221 — BacktestEquityCurve

**Arquivo:** `src/services/backtest_equity_curve.py`

**Comportamento:**
- `build(trades, initial_equity=10_000.0) → List[EquityPoint]`
- Ponto 0 = START (equity = initial_equity, dd = 0.0)
- Apenas WIN/LOSS movem equity; EXPIRED/UNKNOWN ignorados
- `equity = max(equity, 0.0)` — floor em zero
- `drawdown_pct = (peak - equity) / peak × 100`

**Testes:** `tests/test_story_221_backtest_equity_curve.py` (11 testes)
**Doc:** `docs/stories/story-221-backtest-equity-curve.md`

### Story 223 — BacktestRunner + CLI

**Arquivos:**
- `src/services/backtest_runner.py` — BacktestRunner
- `src/backtest/__init__.py` — package
- `src/backtest/__main__.py` — CLI

**BacktestRunner:**
- `async run(symbol, days, ...) → BacktestSummary`
- Pipeline: `SignalLoader → OutcomeSimulator → EquityCurve → MetricsEngine`
- Normaliza símbolo: `"BTCUSDT"` → `"BTC"`
- Retorna summary vazio se não há sinais (sem exception)
- `@staticmethod render_report(summary) → str` — Markdown com tabelas

**CLI:**
```bash
python -m src.backtest run --symbol BTC --days 30
python -m src.backtest run --symbol ETH --days 90 --initial-equity 25000 --seed 42
python -m src.backtest run --symbol SOL --days 60 --output reports/sol.md
python -m src.backtest run --symbol BTC --days 30 --all-signals --quiet
```

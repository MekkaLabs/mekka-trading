### Story 213 — DrawdownMonitor
**Arquivo:** `src/services/drawdown_monitor.py`  
**Testes:** `tests/test_story_213_drawdown_monitor.py` (11 testes)

Serviço que monitora drawdown intraday e dispara alertas Telegram em 3 níveis:
- `WARNING` — 50% do limite diário (`max_daily_drawdown_pct`)
- `CRITICAL` — 80% do limite
- `KILL` — 100% do limite (recomenda `./scripts/kill.sh`)

Dedup interno por nível. Reseta via `reset_session()`. Nunca lança exceção.

```python
monitor = DrawdownMonitor()
alert = await monitor.check(current_equity=9200.0, peak_equity=10_000.0)
# drawdown=8%, limite=10% → 80% → CRITICAL
```

### Story 214 — PositionConcentrationAlerter
**Arquivo:** `src/services/position_concentration_alerter.py`  
**Testes:** `tests/test_story_214_position_concentration_alerter.py` (9 testes)

Monitora se posição individual excede `max_position_size_pct` da equity atual.
Aceita lista de dicts `{symbol, notional_usd, side}`. Dedup por símbolo.

```python
alerter = PositionConcentrationAlerter()
alerts = await alerter.check(
    positions=[{"symbol": "BTC", "notional_usd": 3500.0, "side": "LONG"}],
    equity_usd=10_000.0,
)
# 35% > 25% → ConcentrationAlert
```

### Story 215 — IntradayPnLTracker
**Arquivo:** `src/services/intraday_pnl_tracker.py`  
**Testes:** `tests/test_story_215_intraday_pnl_tracker.py` (10 testes)

### Story 216 — FundingRateMonitor
**Arquivo:** `src/services/funding_rate_monitor.py`  
**Testes:** `tests/test_story_216_funding_rate_monitor.py` (11 testes)

Monitor proativo de funding rates — independente do Batman. Reutiliza os
thresholds de settings (`funding_long_warn_pct`, `funding_long_block_pct`, etc.).
Níveis: WARN e BLOCK para HIGH_LONG e HIGH_SHORT.

```python
monitor = FundingRateMonitor()
alert = await monitor.check(symbol="BTC", funding_rate_pct=0.12)
# 0.12% > 0.10% (block) → FundingAlert(severity="BLOCK")
```

### Story 217 — AlertThrottleManager
**Arquivo:** `src/services/alert_throttle_manager.py`  
**Testes:** `tests/test_story_217_alert_throttle_manager.py` (9 testes)

Gateway centralizado de dedup e throttle. Cooldowns configuráveis por evento.

```python
manager = AlertThrottleManager()
if manager.is_allowed("DRAWDOWN_WARNING", cooldown_seconds=1800):
    await alerter.alert(...)
    manager.record_sent("DRAWDOWN_WARNING")
```

Cooldowns sugeridos:
- `DRAWDOWN_WARNING`: 1800s (30min)
- `DRAWDOWN_CRITICAL`: 900s (15min)
- `DRAWDOWN_KILL`: 300s (5min)
- `POSITION_CONCENTRATION`: 3600s (1h)
- `INTRADAY_PNL_*`: 1800s (30min)
- `FUNDING_*_WARN`: 7200s (2h)
- `FUNDING_*_BLOCK`: 3600s (1h)

## 1. O que foi corrigido

### loadTodaySummary() — reescrita completa

**Problema raiz:** Credenciais Hyperliquid são placeholder (`0x111...1`), então
`self._hl_prices` fica vazio. O widget mostrava `$0.00` onde deveria mostrar `—`.
Além disso, não havia trades de hoje no DB (todos de 2026-05-17 ou antes),
então a lista aparecia vazia sem nenhuma alternativa.

**Fixes entregues:**

| Item | Antes | Depois |
|------|-------|--------|
| `pnl_usd = null` nas posições | Mostrava `$0.00` | Mostra "Aguardando cotação" |
| `has_prices = false` | Sem aviso | Banner ⚠️ amarelo no topo |
| `today_trades` vazio | Lista vazia | Mostra `recent_trades` com data, label "Últimos trades" |
| "Resultado Líquido" sem cotação | Mostrava net_pnl errado | Mostra só realizado |
| Card P&L aberto sem cotação | `$0.00` | `—` + "sem cotação" no subtítulo |
| Erro na API | Sem feedback | Mostra "⚠️ Erro ao carregar" no footer |

**Arquivos modificados:**
- `src/dashboard/static/app.js` — função `loadTodaySummary()` ~linha 5342
- `src/dashboard/static/style.css` — adicionado `.ts-muted` e `.ts-warn-banner`

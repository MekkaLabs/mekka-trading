## Lições técnicas desta sessão

- `@model_validator(mode="after")` em Pydantic v2 é o lugar certo para
  validação cross-field. `@field_validator` só acessa um campo.
- Dois `@model_validator(mode="after")` na mesma classe coexistem bem
  — Pydantic os chama em ordem de definição.
- `preflight_mainnet.py` usa `patch.object(pfm, "is_kill_switch_active", ...)`
  nos testes em vez de `patch("scripts.preflight_mainnet.is_kill_switch_active")`
  — funciona melhor quando o módulo já importou o nome.

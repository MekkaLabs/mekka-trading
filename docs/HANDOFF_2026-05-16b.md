## Contexto

Milestone 29 extrai **cinco padrões novos** do framework [SWE-agent](https://github.com/SWE-agent/SWE-agent)
que não foram cobertos pelo Milestone 23 (Stories 157–159).

O critério de seleção foi: cada padrão deve acrescentar uma camada de observabilidade, segurança
econômica ou qualidade de sinal sem nenhuma dependência externa (sem FAISS, sem DB, sem fila).
Todos os serviços são fail-silent — qualquer exceção vira log de debug e o pipeline continua.

## Stories entregues

### Story 188 — CycleTrajectory
**Padrão SWE-agent:** `Trajectory` / `StepOutput` — log estruturado de cada step do agente, serializável em JSONL.

**Arquivo:** `src/services/cycle_trajectory.py` (NOVO)

**Conceito:**
- `StepRecord(stage, input_summary, output_summary, observation, latency_ms, ok, timestamp)` — um step do ciclo.
- `CycleTrajectory` — sequência append-only de StepRecords por ciclo; `to_jsonl()` serializa cada step como uma linha JSON.
- `TrajectoryStore(max_per_symbol=20, max_total=200)` — singleton; `start_cycle()`, `record_step()`, `finish_cycle()`, `get_recent()`.

**Integração (nick_fury.py):**
```python
# Após ANALYSIS_DONE:
_traj188 = get_trajectory_store().start_cycle(symbol, cycle_id=str(_cycle_id))
get_trajectory_store().record_step(str(_cycle_id), stage="ANALYSIS_DONE", ...)

# Após Vision:
get_trajectory_store().record_step(str(_cycle_id), stage="VISION_SIGNAL", ...)
```

### Story 189 — CycleBudgetGuard
**Padrão SWE-agent:** `max_cost` + `done_status="exit_cost"` — sai graciosamente quando o orçamento LLM é excedido.

**Arquivo:** `src/services/cycle_budget_guard.py` (NOVO)

**Conceito:**
- `BudgetSession(symbol, total_cost_usd, total_calls, session_start, budget_exceeded_at)`.
- `CycleBudgetGuard(max_cost_usd_per_session=1.0, max_calls_per_session=500, auto_reset_hours=24.0)`.
- `should_skip_vision(symbol) → (bool, str)`: retorna `(True, "budget_exceeded(...)")` quando limite atingido.
- Ao contrário de lançar exceção ou travar o pipeline, força um `TradingSignal(HOLD)` — equivalente ao `exit_cost` do SWE-agent.

**Settings:** `llm_budget_max_cost_usd`, `llm_budget_max_calls`, `llm_budget_reset_hours`

**Integração (nick_fury.py):**
```python
# Antes da chamada Vision:
_bskip, _breason = get_cycle_budget_guard().should_skip_vision(symbol)

# No bloco de decisão Vision:
if _budget_skipped:
    signal = TradingSignal(action=TradeAction.HOLD, confidence=0.0,
                           reasoning=f"Budget limit exceeded: {_budget_reason}")

# Após Vision:
get_cycle_budget_guard().record_cost(symbol, estimated_cost_usd=0.002, ...)
```

### Story 190 — SignalDemonstrationStore
**Padrão SWE-agent:** Demonstrations — trajectories de alta qualidade convertidas em YAML e injetadas como few-shot no system prompt.

**Arquivo:** `src/services/signal_demonstration_store.py` (NOVO)

**Conceito:**
- `Demonstration(symbol, regime, signal_json, reasoning, outcome_label, source, confidence)`.
- `matches(symbol, regime)`: match exato + partial (ex: "BULL_HIGH" ↔ "BULL_LOW").
- `SignalDemonstrationStore(max_per_regime=10)`: `add()`, `get_similar(top_n, prefer_wins=True)`, `get_prompt_block()`.
- **Lazy load** de `data/signal_demonstrations.json` na primeira chamada — analistas podem editar em runtime.

**Formato do prompt block:**
```
=== Signal Demonstrations (similar conditions) ===
--- Example Signal (BTC | VOLATILE) ✅ ---
Action: LONG | Confidence: 80% | Entry: 50000.0
Reasoning: strong breakout confirmed by volume...
--- End Example ---
```

**Integração (vision.py):**
```python
# Antes do bloco Story 183:
_demo_block = get_demonstration_store().get_prompt_block(_sym190, regime=_regime190)
if _demo_block:
    prompt = prompt + "\n\n" + _demo_block
```

### Story 191 — ObservationFeedbackLoop
**Padrão SWE-agent:** ACI guardrails + linter observation — após cada `edit`, o agente recebe feedback do linter como contexto para o próximo turn e corrige seus erros.

**Arquivo:** `src/services/observation_feedback_loop.py` (NOVO)

**Conceito:**
- `LintObservation(symbol, rule, field_name, before_value, after_value, description, cycle_id)`.
- `to_prompt_line()`: `"  ⚠ {rule}: {field} was {before} → corrected to {after}. {desc}"`.
- `ObservationFeedbackLoop(max_observations_per_symbol=5)`:
  - `record_from_lint_result(symbol, lint_result)`: usa `fix.before`/`fix.after` do `LintFix`.
  - `get_feedback_block(symbol, consume=True)`: gera bloco e limpa pendências se `consume=True`.

**Formato do prompt block:**
```
=== Lint Observations from Previous Cycle: BTC ===
Your previous signal had geometry issues that were auto-corrected:
  ⚠ clamp [0.0, 1.0]: confidence was 1.25 → corrected to 1.0. ...
  ⚠ LONG: stop_loss >= take_profit → swap: stop_loss/take_profit was SL=55000, TP=49000 → ...
Avoid these geometry errors in your next signal.
```

**Modificação em `auto_signal_linter.py`:**
```python
def lint_and_log(self, signal, last_price=None, symbol=""):
    self._last_result: Optional[Any] = None  # exposto para ObservationFeedbackLoop
    result = self.lint(signal, last_price=last_price)
    self._last_result = result
    ...
```

**Integração (vision.py):** `consume=True` — Vision lê E limpa as observações em uma chamada, garantindo que cada correção seja mostrada exatamente uma vez.

**Integração (nick_fury.py):** Após AutoSignalLinter, se `was_fixed`:
```python
_lint_result_191 = getattr(_linter, "_last_result", None)
if _lint_result_191 and was_fixed:
    get_observation_feedback_loop().record_from_lint_result(symbol, _lint_result_191, ...)
```

### Story 192 — MarketEnvironmentSnapshot
**Padrão SWE-agent:** Environment State Capture — estado do ambiente capturado entre steps para contexto do agente.

**Arquivo:** `src/services/market_environment_snapshot.py` (NOVO)

**Conceito:**
- `EnvironmentSnapshot(symbol, price, regime, cap_tier, rsi, atr, volume_ratio, trend, funding_rate, open_interest, fear_greed_index, has_open_position, current_pnl_usd)` — snapshot imutável via `frozen=True`.
- `to_prompt_block()`: estado de mercado completo formatado para Vision.
- `EnvironmentDiff(price_delta_pct, regime_changed, is_material_change)` — detecta mudança material (>0.5% preço ou regime mudou).
- `MarketEnvironmentSnapshotStore`: `capture(symbol, analysis, cycle_id)`, `diff()` (promove current→previous), `get_prompt_block()`.

**Integração (nick_fury.py):**
```python
# Após ANALYSIS_DONE:
get_env_snapshot_store().capture(symbol, analysis=analysis, cycle_id=str(_cycle_id))
```

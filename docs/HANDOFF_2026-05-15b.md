## Stories Entregues Nesta Sessão (Milestone 21)

### Story 132 — Memory Composite Scoring ✅
**Arquivo:** `src/langgraph/semantic_memory.py`
- `_compute_importance(pnl_usd, max_pnl=200.0)` — normaliza |PnL| para [0,1]
- `_compute_recency_decay(recorded_at, half_life_days=30.0)` — `0.5^(age/half_life)`
- `_Entry` dataclass: novos campos `recorded_at` e `importance`
- `search()` usa composite score: `sem_w×sim + rec_w×decay + imp_w×importance`
- 6 novos settings: `semantic_memory_semantic_weight` (0.5), `recency_weight` (0.3), `importance_weight` (0.2), `recency_half_life_days` (30), `consolidation_enabled` (True), `consolidation_threshold` (0.92)
- 18 testes em `tests/test_story_132_composite_scoring.py`

### Story 133 — Vision Pre-Reasoning ✅
**Arquivo:** `src/agents/vision.py`
- `_PRE_REASONING_SYSTEM` — prompt pedindo 3 parágrafos: Signal Alignment, Key Risks, Preliminary Bias
- `_pre_reason(prompt) → str` — call LLM extra antes do sinal; retorna `""` se < 20 chars
- `_run()` injeta reasoning no prompt final: `"=== Pre-Analysis Reasoning ==="`
- Fail-silent: qualquer erro → prompt normal sem injeção
- `settings.vision_pre_reasoning_enabled = False` (default off)
- 13 testes em `tests/test_story_133_vision_pre_reasoning.py`

### Story 134 — Memory Consolidation ✅
**Arquivo:** `src/langgraph/semantic_memory.py` (entregue junto com 132)
- `_max_cosine_similarity(emb)` — helper para dedup check
- `_consolidate_entries()` — O(N²) sweep pós-warm_up, remove duplicatas cosim ≥ 0.92
- `add()` checa `_max_cosine_similarity` antes de inserir — skip se dup
- Doc: `docs/stories/story-134-memory-consolidation.md`

### Story 135 — Adaptive Layer 1 Routing ✅
**Arquivo:** `src/langgraph/layer1_graph.py`
- `_classify_regime(chart_dict)` — EXTREME/HIGH/LOW/NORMAL via `atr_pct`
- `_decide_skip_set(chart_dict)` — retorna lista de nós a pular por regime
- `routing_node` — novo nó entre superman e fan-out; escreve `skip_set` no estado
- `Layer1State.skip_set: Optional[list[str]]` — novo campo
- Cada nó fan-out (sentiment, onchain, thor, aquaman, flash) checa skip_set
- Topologia: `superman → routing → [fan-out]` (antes: `superman → [fan-out]`)
- 5 novos settings: `layer1_routing_enabled` (False), `layer1_routing_*_skip` (por regime)
- 22 testes em `tests/test_story_135_adaptive_routing.py`

### Story 136 — MekkaEventBus ✅ ← **ÚLTIMA STORY**
**Arquivo:** `src/services/event_bus.py`
- `MekkaEventBus` — pub/sub in-process asyncio
  - `subscribe(topic, handler)`, `unsubscribe`, `publish(topic, payload) → int`
  - Wildcard `"*"` recebe todos os tópicos
  - Fail-silent: erros de handlers logados, não propagam
  - Handlers sync ou async (detectado via `inspect.iscoroutinefunction`)
  - Contadores de eventos, `clear()`, `reset_counters()`
- `get_event_bus()` — singleton global
- `reset_event_bus()` — reset para testes
- `nick_fury._cycle_for_symbol()` publica 5 eventos por ciclo:
  - `cycle.start`, `vision.signal`, `batman.gate`, `ironman.exec`, `cycle.end`
- 24 testes em `tests/test_story_136_event_bus.py`

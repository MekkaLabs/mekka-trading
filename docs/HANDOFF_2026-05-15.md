### Story 130 — Iterative Vision Reflection ← **ÚLTIMA STORY**
**Padrão:** AutoGen Reflection (Coder↔Reviewer iterativo)

**O que foi implementado:**
- `settings.vision_reflection_max_rounds = 3` (novo campo em `settings.py`)
- `Vision.revise(analysis, critique_context, round_num)` — Vision regenera sinal com feedback do Critic no contexto (novo método em `vision.py`)
- `NickFury._vision_reflection_loop(analysis, initial_signal, symbol)` — orquestra o loop (novo método em `nick_fury.py`)
- `_cycle_for_symbol()` substitui o one-shot VisionCritic pelo loop iterativo

**Lógica do loop:**
```
Round 1: Vision S0 → Critic R1
  ENDORSE → return S0                   (2 LLM calls)
  AMEND/REJECT + round < max →
    Vision.revise(S0 + critique) → S1
    Critic R2 → ENDORSE → return S1    (+2 LLM calls)
  AMEND/REJECT + round = max →
    apply_critique() mecânico → return  (fallback)
```
- `max_rounds=1` → comportamento idêntico ao Story 031 one-shot
- Audit log por round: `REFLECTION_R{N}_{ACTION}` no SQLite
- 14 testes criados em `tests/test_story_130_vision_reflection.py`

### Story 131 — Mixture of Agents Vision (MoA) ← **ÚLTIMA STORY** ✅
**Padrão:** AutoGen MoA (Mixture of Agents)

**O que foi implementado:**
- `src/agents/vision_moa.py` — `VisionMoA` class
- `settings.vision_moa_enabled = False` + `settings.vision_moa_min_proposals = 2`
- Toggle em `NickFury._cycle_for_symbol()` (passo 2)

**Arquitetura MoA:**
```
MarketAnalysis
      │
      ├─ GPT-4o (Proposal-A)       ─┐
      ├─ Claude Sonnet (Proposal-B)  ├─→ asyncio.gather → [S-A, S-B, S-C]
      └─ GPT-4o-mini (Proposal-C)   ─┘
                                          │
                                    Orchestrator (GPT-4o > Claude)
                                          │
                                    Consensus TradingSignal
```

**Fail-silent rules:**
- `< 2 proposals OK` → fallback Vision._run() clássico
- Orchestrator falha → `_vote_fallback()` (majority vote + weighted confidence)
- Proposal individual falha → excluída do gather silenciosamente
- `analysis.is_safe_to_trade=False` → HOLD imediato

**Ativação:** `VISION_MOA_ENABLED=true` (default off)

**14 testes** em `tests/test_story_131_vision_moa.py`

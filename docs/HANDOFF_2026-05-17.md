## Story 198 — CycleConversationMemory

**Padrão:** OpenHands `ConversationMemory` (PR #7008 — refactor to helper class for agent history)

Centraliza a lógica de "o que cabe na context window" em vez de deixar cada chamada de LLM
gerenciar diretamente. O CodeActAgent do OpenHands migrou de chamar `message_utils` diretamente
para usar `ConversationMemory` como helper.

**Classes principais:**
- `MessageTurn` (frozen) — par user/assistant de um ciclo com estimativa de tokens
- `CycleConversationMemory` — deque por símbolo com `max_turns_per_symbol=20`
  - `add_turn(symbol, cycle_id, user_prompt, assistant_reply)` → MessageTurn
  - `build_messages(symbol, n_recent)` → `List[{role, content}]` respeitando `max_tokens_budget`
  - `clear_symbol(symbol)` — usado por CycleStateResetter no reset FULL

**Integração em nick_fury.py:**
```python
_conv_mem198 = get_cycle_conversation_memory()
# Após Vision retornar sinal:
_conv_mem198.add_turn(symbol, cycle_id, analysis_summary, f"{signal.action}:{signal.confidence}")
```

## Story 199 — CycleCondensationEngine

**Padrão:** OpenHands `Condenser` / `CondensationAction` (Issues #5715, #6706, PR #7578)

No OpenHands, quando o LLM atinge o context window limit, o AgentController emite um
`CondensationAction` (em vez de manipular a history list diretamente) para auditabilidade.
Duas estratégias: HALVE (corta ao meio) e LLM_SUMMARIZE.

**Classes principais:**
- `CondensationStrategy` — HALVE / SUMMARIZE
- `CondensationRecord` — auditoria (turns_before→after, tokens_before→after, reduction_pct)
- `CycleCondensationEngine`
  - `should_condense(current_tokens, max_tokens)` → bool (threshold default 0.85)
  - `condense_memory(memory, symbol, cycle_id)` → CondensationRecord
  - `maybe_condense(...)` — condensa só se threshold atingido

**Integração em vision.py:**
```python
_cond199 = get_cycle_condensation_engine()
_mem199 = get_cycle_conversation_memory()
_cond199.maybe_condense(memory=_mem199, symbol=sym, current_tokens=len(prompt)//4, max_tokens=8000)
```

## Story 200 — CycleArtifactStore

**Padrão:** OpenHands `FileStore` / `InMemoryFileStore` (openhands-sdk)

Artefatos produzidos por ciclo são keyed por path canônico `symbol/cycle_id[:8]/artifact_type`.
InMemoryFileStore: tudo em dict, sem I/O, adequado para pipeline síncrono.

**ArtifactType enum:**
`SIGNAL | REASONING | RISK_REPORT | MARKET_SNAPSHOT | DELEGATE_OUTPUT | CUSTOM`

**Classes principais:**
- `CycleArtifact` — path + content + metadata + size_estimate
- `CycleArtifactStore`
  - `put(symbol, cycle_id, artifact_type, content, metadata)` → CycleArtifact
  - `get(symbol, cycle_id, artifact_type)` → Optional[CycleArtifact]
  - `list(symbol, cycle_id?)` → List[CycleArtifact]
  - `list_by_type(artifact_type, symbol?, limit)` → List[CycleArtifact]
  - `delete(...)` → bool

**Integração em nick_fury.py:**
```python
_artifact_store200.put(symbol, cycle_id, ArtifactType.REASONING, {
    "action": signal.action.value, "confidence": signal.confidence, "reasoning": ...
})
# No CYCLE_END:
_artifact_store200.put(symbol, cycle_id, ArtifactType.SIGNAL, {
    "action": signal.action.value, "outcome": execution.status.value
})
```

## Story 201 — CycleActionRiskAnalyzer

**Padrão:** OpenHands `SecurityAnalyzer` LLM risk (Issue #10462, CLI `--llm-approve`)

No OpenHands, o SecurityAnalyzer prediz `security_risk` (LOW/MEDIUM/HIGH) para cada ação do
agente. HIGH-risk pode ser bloqueado ou requer confirmação humana.

**ActionRiskLevel enum:** LOW (1) / MEDIUM (2) / HIGH (3)

**Regras de escalada heurística (sem LLM call):**
- Base: HOLD/CLOSE→LOW; OPEN_LONG/SHORT→MEDIUM; SCALE_IN/FORCE_LIQUIDATE→HIGH
- `notional > high_notional_threshold (10K USD)` → escala para HIGH
- `leverage > high_leverage_threshold (5x)` → escala para HIGH
- `regime in (VOLATILE, CRASH, PANIC)` + MEDIUM → escala para HIGH
- `confidence < 0.5` + LOW → escala para MEDIUM
- `block_on_high=True` → `assessment.blocked=True` para HIGH risk

**Integração em nick_fury.py (antes do Batman gate):**
```python
_risk_assessment = _risk_analyzer201.analyze(
    action_type=signal.action.value, symbol=symbol,
    notional=signal.position_size_usd, leverage=signal.leverage,
    regime=analysis.regime, confidence=signal.confidence,
)
if _risk_assessment.blocked:
    logger.warning(f"[RiskAnalyzer HIGH] {symbol} {signal.action} — {_risk_assessment.reason}")
```

## Story 202 — CycleStateResetter

**Padrão:** OpenHands `AgentController.reset()` (openhands/controller/agent_controller.py)

No OpenHands, `reset()` limpa estado efêmero (step count, delegate stack, retry state, cost accumulators)
sem resetar o EventStream (histórico preservado). Permite re-uso do controller para múltiplas tasks.

**ResetScope enum:** CYCLE_START / CYCLE_END / ERROR_RECOVERY / FULL

**Componentes resetados por scope:**

| Componente | CYCLE_START | CYCLE_END | ERROR_RECOVERY | FULL |
|-----------|-------------|-----------|----------------|------|
| CycleAgentStateMachine → IDLE | ✓ | ✓ | ✓ | ✓ |
| VisionRetryMixin counters | ✓ | ✓ | ✓ | ✓ |
| CycleBatchedExporter flush | — | ✓ | — | ✓ |
| CycleConversationMemory clear | — | — | — | ✓ |
| CycleCondensationEngine note | — | ✓ | — | ✓ |
| CycleArtifactStore | NUNCA | NUNCA | NUNCA | NUNCA |

**Integração em nick_fury.py:**
```python
# Início do ciclo:
_resetter202.reset(_RS.CYCLE_START, symbol=symbol, cycle_id=str(_cycle_id))
# Fim do ciclo:
_resetter202.reset(_RS.CYCLE_END, symbol=symbol, cycle_id=str(_cycle_id))
```

### Tarefa C — Fix Bug Babel Loader (Office em branco)

**Problema:** Após ativar `USE_BUNDLE = false`, o Pixel 3D Office aparecia completamente em branco.

**Causa raiz:** O Babel standalone processa `<script type="text/babel">` **apenas** no evento `DOMContentLoaded`. Scripts adicionados dinamicamente via `head.appendChild(s)` após o Babel já ter carregado são **silenciosamente ignorados** — o JSX nunca é transpilado e nenhum React component é montado.

**Código quebrado (antes):**
```js
// ❌ QUEBRADO: tags adicionadas depois do DOMContentLoaded são ignoradas
for (const f of ['tweaks-panel.jsx', ..., 'app.jsx']) {
  const s = document.createElement('script');
  s.type = 'text/babel';   // Babel não vai processar isso!
  s.src = f + '?v=' + v;
  head.appendChild(s);
}
```

**Fix aplicado em `index.html`:**
```js
// ✅ CORRETO: fetch → Babel.transform() → eval em cadeia sequencial
function loadJsxFile(path) {
  return fetch(path)
    .then(r => r.text())
    .then(src => {
      const code = window.Babel.transform(src, {
        presets: ['react'],
        filename: path
      }).code;
      (0, eval)(code); // indirect eval → escopo global, window.* funciona
    });
}

// Sequencial: cada arquivo depende dos globals do anterior
files.reduce((chain, f) =>
  chain.then(() => loadJsxFile(f + '?v=' + v)),
  Promise.resolve()
);
```

**Por que funciona:**
- `fetch()` carrega o source JSX do servidor (same-origin, base `/office-v2/`)
- `Babel.transform()` transpila JSX → JS vanilla imediatamente
- `(0, eval)(code)` executa no escopo global → `Object.assign(window, {...})` funciona
- Sequencial garante que `getPowerLift`/`drawPower` (de `powers.jsx`) estejam no `window` antes de `scene.jsx` carregar

**CSP confirmada:** O servidor (`server.py`) já permite `unsafe-eval` e `https://unpkg.com` para rotas `/office-v2/`:
```python
if request.path.startswith("/office-v2"):
    relaxed = _DASHBOARD_CSP.replace(
        "script-src 'self'",
        "script-src 'self' 'unsafe-eval' 'unsafe-inline'",
    )
```

## Notas técnicas

### Fix Story 138 (vision error observation bug)
O bug era: quando `_vision.run()` lançava exceção, `_llm_error_breaker.observe(True)` nunca era chamado — a exceção propagava antes. Agora o bloco usa `try/except/finally` onde o `finally` sempre chama `observe()` independente do resultado.

### LLMClient interface change (Story 142)
`_call_openai()` e `_call_anthropic()` agora retornam `tuple[str, int, int]` em vez de `str`. Qualquer teste ou código que chame essas funções privadas diretamente vai quebrar — mas são métodos privados (prefixo `_`), então o contrato público (`chat()`) não mudou.

### IronMan paper branch (Story 144)
Quando `mock_realism_enabled=True` e `fill_ratio < 99.9%`, o status é `PARTIAL` em vez de `PAPER`. Verifique se os testes de IronMan que verificam `ExecutionStatus.PAPER` precisam de ajuste (adicionar `mock_realism_enabled=False` no setup).

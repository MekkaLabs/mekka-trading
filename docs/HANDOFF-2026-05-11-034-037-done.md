## Lições técnicas desta sessão

- Sentinel `X = None` no módulo é obrigatório para qualquer lazy import
  que precisa ser patchado por testes com `patch("module.X")`. Aplica-se
  a `Deadpool`, `settings`, `is_kill_switch_active`, `read_kill_switch_metadata`.
- `asyncio.run()` falha se já existe um loop rodando (ex.: pytest-asyncio).
  Fallback: `ThreadPoolExecutor` com `asyncio.run()` num thread isolado.
- Testes de dispatch que verificam roteamento precisam mockar
  `settings.telegram_inbound_allowed_chat_ids = []` para evitar que
  outros testes contaminem o filtro de chat_id.

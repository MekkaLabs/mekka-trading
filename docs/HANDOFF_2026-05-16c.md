## Story 193 — SubAgentDelegator (`sub_agent_delegator.py`)

**Padrão:** OpenHands `AgentDelegateAction` / `AgentDelegateObservation`

O agente pai (`NickFury`) delega tarefas isoladas para sub-agentes com estado próprio.
Delegate retorna `DelegateObservation(outputs=state.outputs)` para o pai. `delegate_level`
rastreia profundidade de aninhamento (máx 2). `is_delegate=True` previne dupla subscrição
ao EventStream no contexto do sub-agente.

**Classes principais:**
- `DelegateTask` — define a tarefa (prompt, agent_type, symbol, max_tokens)
- `DelegateObservation` — resultado (status, outputs, cost_estimated_usd, latency_ms)
- `DelegateStatus` — FINISHED / ERROR / REJECTED / TIMEOUT
- `SubAgentDelegator` — singleton com histórico por símbolo, prompt block helpers

**Uso em NickFury:**
```python
from src.services.sub_agent_delegator import get_sub_agent_delegator, DelegateTask
_delegator = get_sub_agent_delegator()
task = DelegateTask(task="analyze BTC regime", symbol="BTC", ...)
obs = _delegator.delegate(task)
```

## Story 194 — VisionRetryMixin (`vision_retry_mixin.py`)

**Padrão:** OpenHands `RetryMixin` com backoff exponencial

Retry para chamadas LLM do Vision com fórmula:
`wait = min(max_wait, max(min_wait, multiplier × 2^(attempt-1)))`

Defaults: `multiplier=2.0`, `min=1.0s`, `max=8.0s` → waits ~1, 2, 4, 8s.

**Comportamentos especiais:**
- `LLMMalformedActionError`, `LLMNoActionError` → **não retryável** (erro de lógica)
- Resposta vazia (`LLMNoResponseError` ou `empty`, `no response` na mensagem) →
  aplica `temperature_jitter_value=0.7` para quebrar loop determinístico (fix Gemini)
- Fail-silent no final: retorna `None` após exaurir tentativas

**Integração em `vision._call_llm()`:**
```python
for _attempt194 in range(1, _retry194.config.max_retries + 2):
    try:
        _result = await self._llm.chat(...)
        return _result
    except Exception as _exc194:
        if _attempt194 > _retry194.config.max_retries:
            raise
        _wait194 = _retry194._wait_time(_attempt194)
        await asyncio.sleep(_wait194)
```

## Story 195 — CycleAgentStateMachine (`cycle_agent_state.py`)

**Padrão:** OpenHands `AgentState` enum com transições validadas

Estado formal per-símbolo com histórico de transições.

**Estados válidos:**
```
IDLE → SCANNING → ANALYZING → SIGNALING → LINTING → RISK_CHECK → EXECUTING → FINISHED
                                        ↘ RISK_CHECK                                ↓
       (SKIPPED / ERROR em qualquer ponto)                                        IDLE
```

**Blocos em nick_fury.py (fail-silent):**
```python
_state195 = get_cycle_agent_state_machine()
_state195.transition(symbol, _CAS.SCANNING, cycle_id=str(_cycle_id))
# ... após Vision:
_state195.transition(symbol, _CAS.SIGNALING, ...)
# ... antes Batman:
_state195.transition(symbol, _CAS.LINTING, ...)
_state195.transition(symbol, _CAS.RISK_CHECK, ...)
# ... final:
_state195.transition(symbol, _CAS.EXECUTING, ...)
_state195.transition(symbol, _CAS.FINISHED, ...)
_state195.transition(symbol, _CAS.IDLE, ...)
```

**Endpoint pendente:** `GET /api/agent-state` → `_state195.all_states()`

## Story 197 — CycleBatchedExporter (`cycle_batched_exporter.py`)

**Padrão:** OpenHands `BatchedWebHook` — acumula + flush por batch_size

Exporta eventos do ciclo em lotes para webhook externo (Grafana, analytics, dashboard).

**Comportamento:**
- `add(event_dict)` — adiciona ao buffer (drop oldest se `max_buffer_size=200` excedido)
- `maybe_flush()` — flush automático quando `len(buffer) >= batch_size`
- `flush()` — flush manual (chamado no final de cada ciclo em NickFury)
- `_post_batch()` — HTTP POST JSON, fail-silent (qualquer erro vira `logger.debug`)
- `enabled = enabled and bool(webhook_url)` — sem URL → desabilitado automaticamente

**ExportBatch payload:**
```json
{
  "batch_id": "batch-00001",
  "batch_size": 5,
  "timestamp": 1747400000.0,
  "source": "mekka-trading",
  "events": [...]
}
```

**Config via settings:**
```python
settings.cycle_webhook_url          # URL do receptor
settings.cycle_webhook_batch_size   # default 20
settings.cycle_webhook_enabled      # default True
settings.cycle_webhook_headers      # dict extra headers
```

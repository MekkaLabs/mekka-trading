## 1. O que foi feito

### Widget "Resultado do Dia" (Overview — acima do Office)

**Objetivo:** painel simples e direto para quem não entende de trading.

**Novo endpoint:**
- `GET /api/today-summary` em `src/dashboard/server.py`
- Retorna: `open_positions`, `today_trades`, `daily_pnl_usd`, `open_pnl_usd`, `net_pnl_usd`, `day_emoji`, `is_paper`
- Agrega `fetch_positions()` + `list_recent_trades(limit=100)` + `get_today_pnl_usd()` em paralelo

**HTML:** nova `<section id="sec-today-summary" data-page="overview">` inserida ACIMA de `sec-office`:
- Badge laranja "🧪 Modo Paper Trading" quando `is_paper=true`
- 3 big cards: Resultado Líquido / 💰 Realizado Hoje / ⏳ Em Aberto
- Grid de posições abertas (card por posição com símbolo, direção, entrada, preço atual, P&L colorido)
- Lista de trades do dia (horário, símbolo, lado, status, P&L)
- Footer com timestamp de última atualização

**JS (`app.js`):**
- `_PAGE_SECTIONS.overview` → `['sec-today-summary', 'sec-office', 'sec-live-market', 'sec-metrics']`
- `loadTodaySummary()` — fetch + render
- `bootTodaySummary()` — boot + setInterval 30s
- Trigger em `_mkSetPage('overview')` para recarregar ao navegar
- `safeBoot(bootTodaySummary, 'bootTodaySummary')` no `_mkRunAllBoots()`

**CSS (`style.css`):** ~120 linhas novas para `.ts-*` — cards, posições, trades, cores

---

### Fix Memória (🧠 Memory)

**Bug 1 (crítico):** `bootMemory()` verificava `sec.classList.contains('hidden')` mas o sistema de páginas usa `page-section-hidden`. Corrigido para `'page-section-hidden'`.

**Bug 2:** `loadMemory()` nunca era chamado ao navegar para a página Memory. Corrigido em `_mkSetPage()`:
```js
if (pageKey === 'memory' && typeof loadMemory === 'function') loadMemory();
```

**Bug 3 (bônus):** mesmo bug do `.contains('hidden')` estava no `bootLeaderboard()`. Corrigido também.

### Por que setdefault (Story 163)?

O `setdefault()` garante que:
1. Metadata já definida por outros agentes (como Batman tests ou manualmente) não é sobrescrita
2. Em tests, é possível injetar `signal.metadata = {"market_regime": "BEAR"}` e o bloco 163 preserva

### Por que prev=None no SignalChangeLog.record() (Story 167)?

NickFury não mantém o signal do ciclo anterior em memória entre execuções. O design correto é:
- Ciclo N: record(prev=None, curr=signal_N) → all-new record, sem diff real
- Mas: `get_recent(symbol, n=1)` retorna o record do ciclo N-1 se existir no rolling window
- Para diff real entre ciclos, integração futura pode usar `get_last_change(symbol)` para reconstituir

O importante é que action flips são detectados: se o signal_N tem action diferente do signal_N-1
que está no rolling window do SignalChangeLog, `has_action_change=True`.

### ContextWindowTracker modelo (Story 167)

O tracker usa `settings.openai_model` para determinar o `token_limit`. Isso é correto para
ciclos clássicos. No modo LangGraph com Claude (`settings.claude_model`), o model deveria ser
o model Claude — integração futura pode passar o model correto via parâmetro.

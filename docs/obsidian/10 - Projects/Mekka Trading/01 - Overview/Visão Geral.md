# Visão Geral

## Missão

Construir um sistema de trading autônomo modular, observável e seguro, com execução real condicionada a controles formais.

## Princípios

- CLI-first
- Risk-first
- Observability-first
- Paper-first por padrão
- Contratos de dados com Pydantic

## Workflow obrigatório

`INPUT -> ANALYSIS -> DECOMPOSITION -> ROUTING -> EXECUTION -> VALIDATION -> REFLECTION -> OUTPUT`

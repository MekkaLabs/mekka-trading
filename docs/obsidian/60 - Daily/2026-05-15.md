- **GATE_3O_RESET (Story 111)**: a lógica de reset já funcionava naturalmente via `list_recent_closed_trades` — o novo evento é puramente para observabilidade. Não altera comportamento do gate.
- **`/balance`**: usa `aiohttp.ClientSession` com timeout 8s, URL derivada de `settings.hyperliquid_base_url`. Endpoint: `POST /info` com `{"type": "clearinghouseState", "user": wallet}`.
- **LangGraph (`--langgraph`)**: checkpoint por símbolo em SQLite + `interrupt/resume` torna aprovação Telegram durável a restarts.
- **MekkaEventBus**: base para métricas/telemetria desacoplada (ex.: custo LLM, hooks de ciclo) sem editar cada agente.

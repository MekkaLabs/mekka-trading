## 4. Como testar

```bash
# Backtest API
curl -X POST http://localhost:8787/api/backtest/run \
  -H "Content-Type: application/json" \
  -d '{"symbol":"BTC","days":30,"initial_equity":10000}'

# Performance Rolling
curl "http://localhost:8787/api/performance/rolling?symbol=BTC&days=30"

# Batman Timeline
curl "http://localhost:8787/api/risk/batman-timeline?limit=50"

# Concentration
curl "http://localhost:8787/api/risk/concentration"

# Debate on-demand
curl -X POST http://localhost:8787/api/debate/run \
  -H "Content-Type: application/json" \
  -d '{"symbol":"BTC","rounds":2}'
```

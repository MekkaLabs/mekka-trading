⚡ Modos de Trading

Modo Global Define o preset base do sistema (size, leverage, ativos).

Os dois toggles abaixo são overrides aplicados sobre o Modo Global, tanto no trader autônomo (Batman/NickFury) quanto no botão Executar Trade. Super Agressivo força size mínimo 5% e leverage 10x (respeitando o cap do Modo Global). Altcoins expande o universo de ativos.

🚀
Super Agressivo

Força size mínimo 5% e leverage mínimo 10x no trader autônomo. Respeita cap do Modo Global (ex: em conservative, fica em 2%/2x). Para liberar limites maiores, mude o Modo Global primeiro.

OFF
